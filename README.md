# 📦 Gerenciamento de Estoque

Sistema de gerenciamento de estoque para e-commerce e lojas, desenvolvido com React, TypeScript, Node.js e MySQL.

## 🚀 Tecnologias

**Frontend**
- React 19
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router DOM

**Backend**
- Node.js
- Express
- Prisma ORM
- MySQL

## ✨ Funcionalidades

- 📦 **Produtos** — cadastro, edição e exclusão de produtos com categoria e preços
- 🗂️ **Categorias** — organização dos produtos por categoria
- 🔄 **Movimentações** — registro de entradas e saídas de estoque com histórico
- ⚠️ **Alertas** — indicador automático de estoque baixo
- 📊 **Dashboard** — visão geral com total de produtos, valor em estoque e alertas
